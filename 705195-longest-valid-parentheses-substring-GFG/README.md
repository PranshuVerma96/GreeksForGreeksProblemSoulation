Given a string s&nbsp;consisting of opening and closing parenthesis '(' and ')'. Find the length of the longest valid parenthesis substring.A parenthesis string is valid if:For every opening parenthesis, there is a closing parenthesis.The closing parenthesis must be after its opening parenthesis.Examples :Input: s = "((()"
Output: 2
