# [Length of Circular Linked List](https://www.geeksforgeeks.org/problems/length-of-circular-linked-list/1)
## Easy
Given a circular linked list of size n, find the length of the list (total number of nodes). 
Examples:
Input: node[] = [1, 2, 3, 4, 5] 
Output: 5

Input: node = [2, 5, 7, 8, 99, 100]Output: 6
