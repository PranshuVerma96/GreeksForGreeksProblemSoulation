# [Middle of Stack](https://www.geeksforgeeks.org/problems/middle-of-stack/1)
## Easy
Given a stack st[] of size n, find the middle element of the stackNote: In case of even elements, return the first middle from bottom.Examples:Input: st[] = [1, 2, 3, 4, 5]
Output: 3
Explanation: The middle elements is 3.Input: st[] = [1, 2, 3, 4]
Output: 2
Explanation: The two middle elements are 2 and 3. Since we need the middle element closer to the bottom, the answer is 2.
